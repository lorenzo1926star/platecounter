# Plate Counter

App React/Vite per contare targhe con avvio automatico basato su fasce orarie configurabili.

## Funzioni

- Counter multipli.
- Ogni counter può avere fasce orarie proprie.
- I counter partono automaticamente quando una loro fascia è attiva.
- Più counter possono funzionare simultaneamente.
- Il tasto Start è stato rimosso.
- Stop & Save manuale disponibile durante una fascia attiva.
- Salvataggio sessioni in History.
- Salvataggio locale con `localStorage`.

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Puoi caricare questo progetto su GitHub e collegarlo a Vercel, Netlify o GitHub Pages.
